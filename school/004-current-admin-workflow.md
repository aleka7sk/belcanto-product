# Current Administrator Workflow

> Данный документ описывает повседневную работу администратора школы Belcanto.
>
> Его цель — определить обязанности администратора, зоны ответственности и процессы, которые должны быть автоматизированы Belcanto Product.
>
> Документ описывает реальные бизнес-процессы школы, а не пользовательский интерфейс.

---

# Роль администратора

Администратор является координатором школы.

Он обеспечивает бесперебойную работу между учениками, преподавателями и руководителем.

Администратор не принимает педагогические решения, но создает условия, при которых образовательный процесс проходит без организационных проблем.

---

# Основные обязанности

Администратор отвечает за:

- расписание занятий;
- организацию переносов;
- коммуникацию с учениками;
- коммуникацию с преподавателями;
- контроль посещаемости;
- оформление новых учеников;
- сопровождение концертов;
- организационные вопросы школы.

---

# Главный цикл работы

Работа администратора состоит из множества небольших задач.

Основной цикл выглядит следующим образом.

```
Проверка расписания

↓

Обработка изменений

↓

Коммуникация

↓

Контроль проведения занятий

↓

Решение возникающих вопросов

↓

Подготовка следующего дня
```

---

# Работа с расписанием

Расписание является центральным объектом работы администратора.

Он отвечает за:

- создание занятий;
- перенос занятий;
- отмену занятий;
- изменение преподавателя;
- изменение аудитории;
- уведомление участников.

Любое изменение должно сохраняться в истории.

---

# Работа с новыми учениками

После поступления нового ученика администратор:

- проверяет корректность данных;
- закрепляет преподавателя;
- добавляет ученика в расписание;
- предоставляет инструкции;
- отвечает на организационные вопросы.

Belcanto Product должен максимально автоматизировать этот процесс.

---

# Работа с посещаемостью

После проведения занятий администратор отслеживает:

- присутствовал ли ученик;
- были ли отмены;
- были ли переносы;
- требуется ли связаться с учеником.

История посещаемости не должна теряться.

---

# Коммуникация

Администратор ежедневно взаимодействует:

с учениками:

- ответы на вопросы;
- изменения расписания;
- напоминания;
- организационные сообщения.

с преподавателями:

- изменения расписания;
- отмены;
- замены;
- мероприятия.

Belcanto Product должен сократить количество ручных сообщений.

---

# Работа с мероприятиями

Перед каждым мероприятием администратор:

- формирует список участников;
- подтверждает участие;
- согласовывает время;
- готовит организационную информацию;
- взаимодействует с преподавателями.

После мероприятия фиксируются результаты.

---

# Работа с документами

Администратор может работать с:

- договорами;
- согласиями;
- внутренними документами;
- фотографиями;
- организационными материалами.

Конкретный перечень требует уточнения.

---

# Работа с преподавателями

Администратор помогает преподавателям решать организационные вопросы.

Например:

- изменение расписания;
- переносы;
- поиск свободного времени;
- подготовка мероприятий.

Belcanto Product должен уменьшить количество ручной координации.

---

# Работа с руководителем

Администратор предоставляет руководителю информацию о:

- текущем расписании;
- загруженности школы;
- организационных проблемах;
- подготовке мероприятий.

---

# Ежедневные задачи

Каждый рабочий день обычно включает:

- проверку расписания;
- ответы на сообщения;
- решение переносов;
- работу с отсутствующими учениками;
- подготовку ближайших мероприятий;
- коммуникацию с преподавателями.

Belcanto Product должен помогать выполнять эти действия максимально быстро.

---

# Что НЕ входит в обязанности администратора

Администратор не:

- оценивает навыки ученика;
- выбирает репертуар;
- принимает педагогические решения;
- изменяет образовательную программу;
- оценивает качество исполнения.

Эти решения принимает преподаватель.

---

# Автоматизация

Основная задача Belcanto Product — убрать рутинные действия.

Например:

- автоматические напоминания;
- уведомления об изменениях;
- единое расписание;
- история изменений;
- быстрый поиск информации;
- централизованная коммуникация.

---

# Принципы

При проектировании функций администратора необходимо соблюдать следующие правила.

1. Минимум повторного ввода данных.
2. Любое изменение фиксируется.
3. Важные события сопровождаются уведомлениями.
4. Все действия можно отследить.
5. История изменений сохраняется.
6. Организационная работа должна занимать минимальное количество времени.
