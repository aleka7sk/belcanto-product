# Бизнес-цели

> Каких исходов школа ожидает от продукта — и насколько продукт эти исходы определяет.
>
> Каждая цель несёт **категорию атрибуции** (PD-0015). Цель без атрибуции недействительна: она приписывала бы продукту контроль, которого у него нет.

## 5. Validation Rules · Правила валидации

1. Каждая цель выражена как исход для школы или человека, а не как функция продукта.
2. Каждая цель может быть не достигнута — цель, недостижимость которой невозможна, целью не является.
3. Каждая цель прослежена к источнику в состоянии не ниже `Approved` либо к записанному решению.
4. Ни одна цель не формулирует метрику, формулу, целевое значение или срок.
5. Каждая цель несёт категорию атрибуции, механизм вклада продукта и перечень прочих существенных факторов.
6. Перечень исключённых исходов непуст.

## 6. Content · Содержание

### 6.1. Зачем школе этот продукт

Belcanto Product принимает вклад в **долгосрочную коммерческую устойчивость школы** — через увеличение образовательной ценности для учеников, преподавателей и операционных процессов школы.

Это не обязательство по выручке и не обязательство по прибыли. Продукт не владеет финансовыми функциями ([`product/002`](002-product-boundaries.md) §Финансы) и прямой причинности не заявляет. Обязательство принимается **по вкладу**.

BG-07 является верхнеуровневой целью; BG-01…BG-06 суть механизмы, через которые вклад осуществляется.

### 6.2. Горизонт

Горизонт бизнес-целей — **три года**.

Горизонт проектирования остаётся десятилетним ([`product/001-vision-and-principles`](001-vision-and-principles.md) §Long-term Principles) и с горизонтом целей не совпадает: первый задаёт запас прочности решений, второй — срок, на котором цель может быть опровергнута.

### 6.3. Перечень целей

Категории атрибуции определены решением PD-0015.

---

#### BG-01 · Качество образовательного процесса не снижается при росте школы

| | |
|---|---|
| **Атрибуция** | Совместно влияемый |
| **Вклад продукта** | доступность истории обучения преподавателю; высвобождение времени (BG-03); наблюдаемость отставания ученика |
| **Прочие существенные факторы** | компетенция преподавателя — **преобладающий фактор**; программа обучения; усилие ученика; практика найма |
| **Обязательство** | по вкладу; продукт не обязуется по уровню качества |
| **Свидетельство** | индикаторы продукта с явным указанием, что продукт не является преобладающим фактором |
| **Владелец** | Education Lead |
| **Горизонт** | 3 года |
| **Зависимости** | BG-03 |

Продукт **способствует** сохранению качества, создавая условия: преподаватель видит историю, тратит меньше времени на организацию, замечает отставание раньше. Продукт не оценивает качество обучения и не принимает педагогических решений (PP-06).

---

#### BG-02 · Руководитель принимает решения быстрее и на основании данных

| | |
|---|---|
| **Атрибуция** | Влияемый |
| **Вклад продукта** | объединение данных школы в одном месте; объяснимость каждого изменения (PP-07) |
| **Прочие существенные факторы** | качество суждения руководителя; информация, существующая вне продукта |
| **Обязательство** | по исходу, с названным механизмом |
| **Свидетельство** | сравнение до и после внутри продукта |
| **Владелец** | Product Owner |
| **Горизонт** | 3 года |

Продукт **сокращает** время сбора картины — сегодня оно тратится на ручную сборку ([`product/003`](003-personas.md) §Owner). Решение остаётся за руководителем; продукт его не принимает.

---

#### BG-03 · Преподаватели тратят меньше времени на организационную рутину

| | |
|---|---|
| **Атрибуция** | Влияемый |
| **Вклад продукта** | устранение повторного ввода; объединение информации об ученике в одном месте (PP-08) |
| **Прочие существенные факторы** | привычки преподавателя; административная нагрузка школы вне продукта |
| **Обязательство** | по исходу |
| **Свидетельство** | сравнение до и после внутри продукта |
| **Владелец** | Product Owner |
| **Горизонт** | 3 года |

Наиболее прямой вклад продукта в наборе: работа устраняется, а не перераспределяется.

---

#### BG-04 · Преподаватели растут профессионально

| | |
|---|---|
| **Атрибуция** | Наблюдаемый |
| **Вклад продукта** | предъявление информации, полезной для роста: нагрузка, история работы, результаты учеников |
| **Прочие существенные факторы** | обучение и обратная связь от руководителя; опыт; собственная инициатива преподавателя |
| **Обязательство** | сделать наблюдаемым; продукт не обязуется двигать этот исход |
| **Свидетельство** | записи продукта |
| **Владелец** | Education Lead |
| **Горизонт** | 3 года |

Продукт **делает наблюдаемым** то, что помогает руководителю развивать преподавателей. Продукт не моделирует преподавателя как развивающегося субъекта (PD-0016, D-3) и не обосновывает финансирование этой целью.

---

#### BG-05 · Ученики удовлетворены обучением

| | |
|---|---|
| **Атрибуция** | Совместно влияемый |
| **Вклад продукта** | понятность следующего шага; видимость собственного прогресса; спокойствие ([`product/003`](003-personas.md) §Student) |
| **Прочие существенные факторы** | отношения с преподавателем — **преобладающий фактор**; достигнутые результаты; цена; окружение |
| **Обязательство** | по вкладу |
| **Свидетельство** | индикаторы продукта с перечнем прочих факторов |
| **Владелец** | Product Owner |
| **Горизонт** | 3 года |

---

#### BG-06 · Ученики продолжают обучение дольше

| | |
|---|---|
| **Атрибуция** | Совместно влияемый |
| **Вклад продукта** | образовательный опыт; поддержка мотивации; видимость прогресса; сообщество; организационное удобство |
| **Прочие существенные факторы** | цена; отношения с преподавателем; жизненные обстоятельства; достигнутые результаты; конкурирующие занятия |
| **Обязательство** | по вкладу; единоличная причинность не заявляется никогда |
| **Свидетельство** | индикаторы продукта с обязательным перечнем прочих факторов |
| **Владелец** | Product Owner |
| **Горизонт** | 3 года |
| **Зависимости** | BG-05 |

Продукт **способствует** продолжению обучения. Давление на удержание не должно порождать назойливость: ограничение задано принципом PP-03 «Мотивация важнее контроля». Опыт уведомлений ([`experience/009`](../experience/009-notification-experience.md)) является будущим руководством по реализации, а не источником ограничения.

---

#### BG-07 · Продукт способствует коммерческой устойчивости школы

| | |
|---|---|
| **Атрибуция** | Совместно влияемый |
| **Вклад продукта** | через BG-01…BG-06: сохранённое качество, сокращённые издержки, продолжающееся обучение |
| **Прочие существенные факторы** | ценообразование; найм; рынок; управленческие решения владельца; расходы вне продукта |
| **Обязательство** | по вкладу; **не по выручке и не по прибыли** |
| **Свидетельство** | вклад через нижележащие цели; финансовый результат наблюдается вне продукта |
| **Владелец** | Product Owner |
| **Горизонт** | 3 года |
| **Зависимости** | BG-01, BG-02, BG-03, BG-05, BG-06 |

Верхнеуровневая цель: она отвечает на вопрос, зачем продукт финансируется. Продукт не владеет финансовыми функциями и финансового результата не измеряет — он обязуется по образовательной ценности, из которой устойчивость следует.

При конфликте с образовательной ценностью действует ранжирование раздела 6.5: коммерческий возврат уступает.

---

#### BG-08 · Школа растёт до нескольких филиалов

| | |
|---|---|
| **Атрибуция** | Наблюдаемый |
| **Вклад продукта** | продукт не препятствует росту: работоспособность при увеличении числа учеников и филиалов ([`product/000`](000-product-overview.md) §Масштабируемость) |
| **Прочие существенные факторы** | решения владельца; капитал; найм; рынок |
| **Обязательство** | сделать наблюдаемым |
| **Свидетельство** | записи продукта |
| **Владелец** | Product Owner |
| **Горизонт** | 3 года |

Рост школы продуктом не движется. Работоспособность при росте является требованием качества, а не бизнес-целью, и в настоящем перечне не учитывается.

### 6.4. Исходы вне зоны продукта

Следующие исходы относятся к категории **Внешний** и целями продукта не являются.

| Исход | Основание |
|---|---|
| Выручка, прибыль, финансовая отчётность, касса, налоги | [`product/002`](002-product-boundaries.md) §Финансы |
| Лиды, воронки продаж, конверсии, маркетинговые кампании | [`product/002`](002-product-boundaries.md) §CRM |
| Кадровый учёт, отпуска, расчёт рабочего времени | [`product/002`](002-product-boundaries.md) §HR |
| Реклама, таргетинг, SEO, email-маркетинг | [`product/002`](002-product-boundaries.md) §Маркетинг |
| Продажа товаров, заказы, складской учёт | [`product/002`](002-product-boundaries.md) §Интернет-магазин |

Внешний исход **допускается цитировать как контекст** и **не допускается вносить в перечень целей**. Изменение перечня требует изменения границ продукта, а оно допускается только записанным решением ([`product/002`](002-product-boundaries.md) §Изменение границ).

### 6.5. Ранжирование целей

При конфликте между целями действует приоритет, установленный [`product/003-personas.md`](003-personas.md) §Конфликт интересов:

1. Образовательная ценность
2. Польза для ученика
3. Польза для преподавателя
4. Польза для школы

Коммерческий возврат относится к четвёртому уровню. Настоящий документ ранжирования не вводит и не изменяет — он его применяет.
