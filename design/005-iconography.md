## 5. Validation Rules · Правила валидации

Документ считается валидным, если выполнены все условия:

1. Одна иконка не обозначает два разных смысла.
2. Иконка без подписи допускается только для смыслов из утверждённого списка.
3. Каждая иконка имеет текстовую альтернативу по design/009-accessibility.md.

Дополнительно применяются общие правила: [`meta/006-validation-rules.md`](../meta/006-validation-rules.md)
