## 5. Validation Rules · Правила валидации

Документ считается валидным, если выполнены все условия:

1. Для каждого типа задачи указан конечный список документов.
2. Список всегда включает документ-владелец затрагиваемого понятия.
3. Протокол запрещает изменение документа без чтения его зависимостей.

Дополнительно применяются общие правила: [`meta/006-validation-rules.md`](../meta/006-validation-rules.md)
