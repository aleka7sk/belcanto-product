# Правила терминологии

> Расхождение в терминах — самый тихий вид конфликта. Два документа употребляют одно слово, каждый в своём смысле, и оба выглядят согласованными до тех пор, пока кто-то не попытается выполнить оба.
>
> Стандарт устраняет это не соглашением о словах, а запретом на второе определение.

---

## 1. Purpose · Назначение

Обеспечить, чтобы каждое слово, имеющее в корпусе специальное значение, имело ровно одно определение, одно место хранения и одно употребление.

## 5. Validation Rules · Правила валидации

1. Критерий раздела 6.1 даёт однозначный ответ для любого слова.
2. Требования к форме определения раздела 6.3 проверяемы без знания предметной области.
3. Ни одно правило не предписывает конкретных терминов.

## 6. Content · Содержание

### 6.1. Что становится термином

Слово признаётся термином при выполнении **любого** условия:

| # | Условие |
|---|---------|
| T1 | Неверное понимание слова приводит к неверному действию |
| T2 | Слово употребляется в корпусе иначе, чем в общем языке |
| T3 | Слово именует объект, состояние или роль, на которые ссылаются другие документы |
| T4 | Слово встречается в идентификаторах или реестрах |

Слово, не удовлетворяющее ни одному условию, термином **не является** и НЕ ДОПУСКАЕТСЯ вносить в реестр. Реестр, наполненный общеупотребительными словами, перестаёт читаться, и настоящие термины теряются среди них.

### 6.2. Единственность определения

1. Каждый термин ОБЯЗАН быть определён ровно в одном документе-владельце.
2. Ни один другой документ НЕ ДОПУСКАЕТСЯ содержащим определение того же термина, включая краткое пояснение «в скобках».
3. Употребление термина вне документа-владельца выполняется ссылкой, а не повторным определением.
4. Краткое пояснение при первом употреблении ДОПУСКАЕТСЯ, только если оно дословно совпадает с определением владельца; иначе оно является вторым определением (DES-009, детектор A4).

Пункт 4 — источник большинства расхождений: пояснение «своими словами» вводится из вежливости к читателю и немедленно начинает расходиться с оригиналом.

### 6.3. Форма определения

Определение ОБЯЗАНО удовлетворять требованиям:

| # | Требование |
|---|------------|
| F1 | Указан род и отличительный признак: «X — это <род>, который <отличие>» |
| F2 | Объём не превышает трёх предложений |
| F3 | Определение не содержит самого определяемого слова |
| F4 | Определение не опирается на неопределённые термины |
| F5 | Определение не содержит правил применения — только смысл |
| F6 | Определение не содержит примеров |
| F7 | Определение не ссылается на реализацию |

F5 существен: правила применения меняются чаще смысла. Определение, включающее правила, требует изменения при каждом изменении правил и тянет за собой каскад по всему корпусу.

### 6.4. Омонимия запрещена

1. Одно слово НЕ ДОПУСКАЕТСЯ имеющим два значения в корпусе, даже в разных слоях.
2. Разрешение выполняется **переименованием**, а не уточнением по контексту.
3. Довод «из контекста понятно» НЕ ПРИНИМАЕТСЯ: контекст теряется при цитировании, поиске и чтении агентом.
4. Обнаруженная омонимия — конфликт класса K2 (DES-009) и обрабатывается как конфликт.

### 6.5. Синонимия

1. Для каждого понятия объявляется **одно** каноническое имя.
2. Синонимы ДОПУСКАЮТСЯ к перечислению в реестре с пометкой «неканонический».
3. Неканонический синоним НЕ ДОПУСКАЕТСЯ к употреблению в документах.
4. Перечисление синонимов служит поиску и распознаванию, а не разрешению употребления.

### 6.6. Употребление

1. Термин употребляется в канонической форме без вариаций.
2. Первое употребление термина в документе СЛЕДУЕТ сопровождать ссылкой на документ-владелец.
3. Повторные употребления в том же документе ссылки не требуют.
4. Термин НЕ ДОПУСКАЕТСЯ к употреблению в значении, отличном от зарегистрированного, даже с оговоркой.
5. Слово из перечня запрещённых (если такой ведётся привязкой) НЕ ДОПУСКАЕТСЯ ни в документации, ни в производных материалах.

### 6.7. Устаревание термина

1. Термин НЕ ДОПУСКАЕТСЯ к удалению из реестра: удалённый термин продолжает существовать в прежних документах и внешних материалах.
2. Устаревший термин помечается как выведенный из употребления с указанием заменяющего.
3. Запись сохраняет прежнее определение: она нужна тем, кто встретит слово в старом тексте.
4. Употребление выведенного из употребления термина в новых документах НЕ ДОПУСКАЕТСЯ.

### 6.8. Изменение термина

| Вид изменения | Класс | Требования |
|---------------|-------|------------|
| Уточнение формулировки без изменения смысла | `PATCH` | проверка употреблений не требуется |
| Расширение или сужение смысла | `MAJOR` | миграция класса M-C; проверка **всех** употреблений |
| Переименование | `MAJOR` | миграция класса M-C; замена всех употреблений; прежнее имя — в синонимы с пометкой |
| Вывод из употребления | `MAJOR` | миграция класса M-C; указание замены |
| Передача владения термином | — | миграция; см. DES-007, раздел 6.7 |

**Переименование термина — миграция, а не правка.** Оно затрагивает все документы, все реестры, все идентификаторы и все внешние материалы. Выполняется по DES-015.

### 6.9. Термины и идентификаторы

1. Идентификатор ОБЯЗАН быть устойчив к переименованию термина.
2. Ссылки между документами выполняются по идентификатору, а не по имени термина (DES-005).
3. Изменение имени термина НЕ ДОПУСКАЕТСЯ влекущим изменение идентификаторов: иначе каждое уточнение формулировки ломает корпус.

Это правило делает переименование дорогой, но выполнимой операцией. Без него оно становится невыполнимой.

### 6.10. Язык

1. Объявляется **один** исходный язык корпуса.
2. Определение существует на исходном языке. Переводы являются производными и не определяют.
3. Расхождение перевода и оригинала разрешается в пользу оригинала без обсуждения.
4. Термин, не имеющий устоявшегося перевода, СЛЕДУЕТ оставлять на исходном языке, а не переводить приблизительно.
5. Технические имена, идентификаторы и ключи метаданных ДОПУСКАЕТСЯ вести на языке, отличном от исходного языка содержания, если это объявлено привязкой.

### 6.11. Проверки

| # | Проверка | Авто |
|---|----------|------|
| TM1 | Каждый термин определён ровно в одном документе | да |
| TM2 | Каждый термин реестра имеет документ-владелец | да |
| TM3 | Нет определений термина вне документа-владельца | частично |
| TM4 | Нет расхождений кратких пояснений с определением | частично |
| TM5 | Нет омонимов | да |
| TM6 | Неканонические синонимы не употребляются в документах | да |
| TM7 | Выведенные из употребления термины не употребляются в новых документах | да |
| TM8 | Определения соответствуют требованиям F1–F7 | нет, человек |
| TM9 | Каждое имя, употребляемое как термин, присутствует в реестре | частично |

TM9 обнаруживает обратную ошибку: слово используется как термин, но никогда не было определено. Она встречается чаще, чем двойное определение, и обнаруживается позже.
