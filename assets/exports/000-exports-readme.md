## 5. Validation Rules · Правила валидации

Документ считается валидным, если выполнены все условия:

1. Каждый экспорт указывает исходный документ и его версию.
2. Устаревший экспорт помечается как устаревший.
3. Экспорт никогда не редактируется напрямую.
